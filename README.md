# Speed Circuit 3D

Speed Circuit 3D is an open-source racing and open world game built entirely with HTML and CSS — no game engines, no frameworks, just plain web tech pushed to see what it can do. It's a fun side project.

---

## About

The game drops you into an open world where you can drive around freely or race across circuits. It has 3D-styled vehicles and a handful of different biomes to explore. The whole thing built in HTML and CSS and JS used as the medium for the game.

---

## Features

- Open world you can roam freely
- Racing across circuits
- 3D vehicle models built in pure HTML & CSS
- Multiple biomes with distinct looks
- Just HTML CSS and JS.

---

## Versions

The repository holds every iteration of the game as separate numbered files. The file with the highest number is always the latest version. It's a simple way to see how the project has changed over time.

---

## Getting Started

No install process, no dependencies, no build step.

1. Clone the repo:
   ```bash
   git clone https://github.com/Coder3601/Speed-Circuit-3D.git
   ```
2. Open the latest numbered HTML file in your browser.
3. That's it.

---

## Performance

The game can be graphically intensive due to the way 3D effects are handled in CSS. It may lag or run slowly on older or lower-end machines. This is a known limitation of building something like this with pure HTML and CSS, and something to be aware of before playing.
